Par exemple, les mots *onirique* et *ironique* ayant les mêmes lettres avec le même nombre d'occurrences (un *n*, deux *i*, etc.), ce sont des anagrammes l'un de l'autre. ## Détection d'anagramme Définissez une fonction `std::string normalize(std::string const &)` ayant la spécification suivante : la chaîne renvoyée doit être la même pour toutes les anagrammes du mot passé en argument ; elle doit être différente pour deux mots qui ne sont pas des anagrammes. Par exemple, `"eiinoqru"` est une forme normale convenable pour *onirique* et *ironique* (d'autres façons de normaliser sont possibles). **Indications :** - Vous pouvez utiliser `std::sort`. - Si la chaîne de caractère d'entrée contient des espaces, ceux-ci sont retirés par `normalize`. - De même, `normalize` transformera toute potentielle majuscule en minuscule. Utilisez cette fonction pour définir une fonction `bool are_anagrams(std::string const &, std::string const &)` prenant deux chaînes de caractères en argument et renvoyant `true` si ces deux chaînes sont anagrammes l'une de l'autre. Testez votre fonction sur quelques exemples dans la fonction `main` et affichez-les. ## Chargement de mots Définissez une fonction `std::vector load()` qui lit le fichier [**`words.txt`**](words.txt) et renvoie un vecteur de chaînes de caractères contenant un mot par case. Vous utiliserez préférentiellement `std::getline(std::istream &, std::string &)` pour effectuer la lecture du fichier depuis un `std::ifstream`. Testez votre fonction dans `main` en affichant la longueur du vecteur (le nombre de mots lus) ainsi que le dernier mot. *(Note : le zyzzyva est un coléoptère tropical.)* ## Construction de dictionnaire L'objectif est maintenant de construire un dictionnaire permettant d'inverser la fonction `normalize`. Autrement dit, pour toute chaîne `s`, une expression ressemblant à `dict[normalize(s)]` doit permettre de retrouver entre autres la valeur `s`. Vous utiliserez pour cela le conteneur `std::multimap` qui est une table de hachage à valeurs multiples : ```cpp using dictionary = std::multimap; ``` **Question :** Pourquoi est-ce que `std::map` ne convient pas ? *(Répondez sous forme de commentaires à la fin du fichier `.cpp`)* Définissez une fonction `dictionary convert(std::vector const &)` qui crée et remplit un dictionnaire à l'aide des mots passés en argument. **Note :** `std::multimap::insert` prend en argument une paire formée de la clé et de la valeur associée. ## Liste des anagrammes d'un mot Définissez une fonction `std::vector anagrams(dictionary const &, std::string const &)` qui renvoie toutes les anagrammes d'un mot (excepté lui-même) présentes dans un dictionnaire : ```cpp std::vector anagrams(dictionary const &, std::string const &); ``` **Note :** La méthode `equal_range` de `std::multimap` renvoie une paire d'itérateurs qui délimitent la zone contenant toutes les entrées d'un dictionnaire ayant la même clé.
